          Dev & Test Tools

          Extra tooling for reproducible testing across versions — not the normal workflow; use the form on the left for everyday use. Importing a test case overwrites fixed events / tasks / preferences / protected blocks wholesale with the JSON content, and pins "This Week" to the week the JSON specifies, so different versions of the scheduler can be compared on identical input.

          Reset clears fixed events, tasks, preferences, protected blocks, and the currently displayed week's reflection notes, and unpins the week back to the live current week. This cannot be undone.
