週間手帳

固定行程・任務・偏好都在這裡輸入，週計畫自動排好

固定行程

上課、上班、通勤、會議這類不會動的時段。

    任務

    Must / Want / Optional 由你自己判斷 — 這是你的優先順序,不是系統幫你決定的。

      偏好設定

      這些是你自己的決定 — AI 只會照著排，不會自己決定要保留哪些時段或犧牲什麼。

      每天可排程的時間範圍

      保護時段（無論如何都保留）

        想固定維持的活動（運動、閱讀…）直接在左邊「任務」新增，分類選 Want、截止時間留空、填「每週次數」即可 — 不用在這裡重複設定。

        時間不夠時,犧牲順序（由上而下先犧牲）

        must 任務與保護時段永遠不在這個清單裡。

          開發 / 測試工具（Dev & Test Tools）

          給版本間可重現測試用的額外工具，不是一般使用流程 — 平常請照左邊表單操作。匯入測試案例會用 JSON 內容整批覆蓋固定行程／任務／偏好／保護時段，並把「本週計畫」鎖定在 JSON 指定的那一週，這樣不同版本的排程器可以在完全相同的輸入下比較輸出。

          重置會清空固定行程、任務、偏好設定、保護時段、目前顯示週的回顧筆記，並解除鎖定週，回到即時的本週。此動作無法復原。
